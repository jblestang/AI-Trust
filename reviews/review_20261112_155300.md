## 1. Intégration de l'Invariance de Trace Globale (#1 - Trace Refinement)

Pour dépasser la simple vérification par transition unitaire, nous avons introduit un modèle mathématique de l'historique d'émission de la Machine A :

- Prédicat : `contains_emission(trace: Seq<EmittedPdu>, seq: u64, field: u64) -> bool`

### 1.2 Théorème de Non-Falsification de Trace (`theorem_trace_authenticity_and_soundness`)
```rust
pub proof fn theorem_trace_authenticity_and_soundness(
    trace_a: Seq<EmittedPdu>,
    seq: u64,
    received_field: u64,
    expected_digest: u64,
)
    requires
        exists|i: int| #![auto] 0 <= i < trace_a.len() && trace_a[i].seq == seq && crypto_hash_spec(trace_a[i].protected_field) == expected_digest,
        crypto_hash_spec(received_field) == expected_digest,
    ensures
        contains_emission(trace_a, seq, received_field),
```
**Garantie formelle :** Prouve que si Machine B valide un paquet avec un certain payload, ce payload a **strictement été émis par Machine A** dans son historique. Aucun attaquant manipulant le réseau ne peut injecter ou altérer un paquet validé (*Trace Soundness & Anti-Forgery*).

## 2. Intégration de la Vivacité Temporelle sous Gigue Bornée (#4 - Real-Time Liveness)

Pour éliminer l'angle mort sur le temps réel et les faux positifs de délai, nous avons modélisé les arrivées dans l'espace des horloges logiques (*ticks*) :

### 2.1 Modélisation Temporelle
- Structure : `TimedNetworkEvent { seq: u64, pdu_arrival_tick: u64, trust_arrival_tick: u64 }`

### 2.2 Théorème de Vivacité sous Gigue Bornée (`theorem_bounded_jitter_liveness`)
```rust
pub proof fn theorem_bounded_jitter_liveness(
    event: TimedNetworkEvent,
    window_capacity_ticks: u64,
)
    requires
        window_capacity_ticks > 0,
        event.pdu_arrival_tick <= event.trust_arrival_tick ==> (event.trust_arrival_tick - event.pdu_arrival_tick) < window_capacity_ticks,
        event.trust_arrival_tick <= event.pdu_arrival_tick ==> (event.pdu_arrival_tick - event.trust_arrival_tick) < window_capacity_ticks,
    ensures
        event.pdu_arrival_tick <= event.trust_arrival_tick ==> event.trust_arrival_tick < event.pdu_arrival_tick + window_capacity_ticks,
        event.trust_arrival_tick <= event.pdu_arrival_tick ==> event.pdu_arrival_tick < event.trust_arrival_tick + window_capacity_ticks,
```
**Garantie formelle :** Prouve mathématiquement que dès lors que la gigue d'arrivée entre le flux de données et le flux de confiance reste inférieure à la capacité temporelle de la fenêtre ($W \times \tau$), le descripteur et le PDU se corrèlent **toujours avant l'éviction**. Il est mathématiquement garanti qu'aucun faux positif d'injection (`AddedPdu`) ou de perte (`DroppedPdu`) ne peut être déclenché par un simple retard réseau.
